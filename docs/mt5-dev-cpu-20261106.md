## Chạy lại và rollback

`docker restart mdg-terminal-1` giữ image hiện tại và volume. Recreate phải dùng
release Compose của lượt này với `MT5_IMAGE` bằng image ID ở trên, base Compose
MDG revision `9ca69a5...` và private override hiện có. Không chạy lại
`apply_terminal.py`: script đó là cutover một lần và kiểm image cũ trước khi chạy.

`backups/mt5-cpu-20261106-7e2322b850ae/rollback.json` giữ image/config files cũ.
Rollback thông thường chỉ recreate terminal bằng image cũ
`sha256:68097d23f60408f35f343572ad391a05f9296029211e1c64d759fddbd7fbe8dc`
và ba Compose files ghi trong đó; không restore/xóa toàn volume hoặc database.
Giữ token/config private mode 600 nếu cần phục hồi file cấu hình từ archive.

Chưa soak dài, chưa đo latency SLO, chưa thay kernel/Wine hoặc nâng source `dev`.
Postman CLI chưa cài; dùng HTTPX/WS verifier với assertions thật. Không thay API
contract hay source ứng dụng trong lượt deploy này; local verification của image
